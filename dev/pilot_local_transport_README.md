# 로컬 전송 마감 검증

이 검증은 고정된 로컬 Python 작업자만 실행합니다. 실행 파일과 작업자 코드는 SHA-256으로 고정하며, 변경 가능한 실행 명령·외부 모델·API 키를 받지 않습니다. Linux bwrap에서 소켓 관련 시스템 호출을 seccomp로 제한하고, 전달 환경과 파일 디스크립터를 최소화했습니다. 역사적 A0 개발용 메뉴를 재사용하며 새 후보나 평가 데이터를 만들지 않습니다.

```sh
cd dev
tools/pilot_local_transport_sandbox.sh --test
# 별도 재현용 복사본에서만. 기존 증거는 덮어쓰지 않습니다.
tools/pilot_local_transport_sandbox.sh
```

- 요청·응답은 각 8 KiB 한도입니다. 초과 응답의 감지에 사용하는 추가 1바이트는 반환하지 않습니다.
- 유효한 응답, 성공 종료, 프로세스 회수가 모두 마감 전에 확인된 경우만 결과를 반환합니다. 지연 작업은 SIGKILL로 종료하고 회수합니다. 영수증의 경과 시간은 실패 후 회수에 걸린 시간도 포함합니다.
- 성공, 실제 수면 중단, 잘못된 JSON, 초과 응답, 초과 요청 증거는 `evidence/pilot_local_transport/`에서 확인할 수 있습니다. 정상 응답 파일 하나만 기록했습니다.
- 이 실험은 신뢰한 로컬 자식 프로세스에 한정됩니다. 시스템 스케줄링이나 운영체제 멈춤을 포함한 실시간 상한을 보장하지 않습니다. 실제 모델 서비스의 응답 취소, 정확한 모델 구성 식별, 비용·토큰 영수증, 동등 예산 대조는 테스트하지 않았습니다.
