      05 / Verification boundary

      검증 범위와 한계

      동치와 깊이

      정확한 입력·출력 순서에서 원본과 동치인지 검증했습니다. AND 수는 도달 가능한 게이트만 세고, 깊이가 증가하거나 AND 수가 줄지 않으면 원본을 유지합니다.

      개발 전용

      고정 행동은 기존 학습용 그룹에서 선정했습니다. 개발 그룹 반복은 독립 표본이 아닙니다. 관측 상한은 실행 뒤 고른 비교점이지 사용할 수 있는 예측 모델이 아닙니다.

      아직 미검증

      동일 예산 라이브 AI 효과, 새로운 비공개 문제에서의 일반화, 실제 처리 시간·ASIC 비용과 BTC 채굴 절감은 측정하지 않았습니다.
