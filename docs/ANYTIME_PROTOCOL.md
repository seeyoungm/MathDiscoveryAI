# 사전 고정 · 시간 예산 개발 리허설

질문: 같은 후보 목록과 제한 안에서, 구조만 보는 고정 순서와 기본 순서를
비교하는 기록·검증·시각화가 작동하는가? 라이브 AI나 ABC와의 성능 비교가 아니다.

- 사람이 만든 A 3개와 B 3개, 사전 정의한 함수만 사용한다. 독립 평가나
  신규 분포가 아니다. 이미 본 문제로 취급하고 일반화나 학습에는 쓰지 않는다.
- 각 사례에서 동일한 시작 AIG, 같은 최초 최대 20개 후보 목록, 최대 8개
  시도, 800 ms 벽시계 예산, 후보별 검사 최대 120 ms. 3회 반복,
  짝 내 실행 순서를 사례와 반복 번호에 따라 교대한다. 직렬 실행.
- 기본군은 후보 원래 순서로 시도한다. 구조군은 A에서 역순 변수 순서에
  가까운 후보, B에서 제거·흡수·인수분해 등 간소화 규칙을 우선한다.
  결과와 시간에 맞춰 조정하지 않는다.
- 메서드별 후보 생성/정렬 직전부터 단조 시계를 사용한다. 공통 시작 회로
  생성은 재사용하며 시간에 넣지 않는다. 동치 검사 및 깊이 판정 완료 때
  시각을 기록한다. 정확 열거와 Z3가 모두 동치임을 보여야 하며, 원본
  깊이 이내의 엄격한 AND 수 감소만 점수에 반영한다. 이 리허설에서는
  별도 외부 프로세스인 Z3에 시간 제한을 주되 전체 원격 취소를 시험하지 않는다.
- 목표는 사례별 원본 AND 수보다 1 작음. 마감 시 최선, 목표 도달 시점,
  거절·미확인·마감 초과를 보존한다. 마감 동시(<=800 ms)는 포함하고 이후에는
  제외한다. 비교 표와 차트는 전체 로그에서 재계산한다.
- 로컬 시간은 호스트 상태에 민감하다. 3회 반복은 독립 사례가 아니며
  어느 방식의 속도 우위를 주장하지 않는다. 모형 호출, 랭커 학습, 홀드아웃,
  C/D/E, 암호 및 채굴 관련 실행은 하지 않는다.
