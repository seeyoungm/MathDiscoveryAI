# MathDiscoveryAI

작은 합성 회로에서 입출력 동치를 유지하고 깊이 제한을 지키면서 AND 게이트 수를 줄이는 방법을 실험합니다.

- [오프라인 대시보드](dashboard/index.html): 저장소를 내려받아 브라우저에서 열면 실험 기록과 시간 비교 그래프를 볼 수 있습니다.
- [최신 실험과 재현 방법](docs/ANYTIME_RESULTS.md): 합성 회로 6개에서 AI 없이 두 후보 순서를 비교했습니다. 양쪽 모두 18회 중 12회 목표에 도달했습니다.

이 공개본에는 도구·테스트·대시보드와 재현에 필요한 합성 A/B 개발 자료만 있습니다. 과거 평가 결과와 원시 로그, 바이너리, 비공개 평가 및 백업은 포함하지 않습니다. 일부 과거 데이터가 필요한 테스트는 이 공개본에서 건너뜁니다. 실제 AI 모델의 우위나 채굴 성능을 검증한 결과가 아닙니다.
