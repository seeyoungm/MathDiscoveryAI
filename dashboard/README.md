# MathDiscoveryAI 실험 기록실

`index.html`을 브라우저에서 열면 네트워크 없이 볼 수 있습니다. 프로젝트 루트에서 다음 명령으로 재현합니다.

```sh
PYTHONDONTWRITEBYTECODE=1 python3 dashboard/build.py
PYTHONDONTWRITEBYTECODE=1 python3 dashboard/test_builder.py
node dashboard/test.mjs
```

기존 주차별 기록과 이전 후속 실험을 보존합니다. 최신 보완 행동과 오프라인 비교 결과는 별도의 독립 검토 영수증에 PASS와 일치하는 SHA-256이 있는 경우에만 나타납니다. 빌더는 그룹별 수치와 합계를 다시 대조합니다. 영수증이 없거나 해당 결과가 검토 보류인 경우 수치는 표시하지 않으며, 불일치는 빌드를 중단합니다.

선택 사항인 로컬 제한 시간 카드는 별도의 독립 검토와 해시를 요구합니다. 실행한 것은 가짜 응답 프로세스뿐이며 모델 응답 시간이나 비용 측정은 아닙니다.

오프라인 비교는 원래 후보 메뉴에 대한 인덱스 해석을 확인하는 개발 예제입니다. 라이브 모델 비교, 비공개 평가, 하드웨어·채굴 성능을 뜻하지 않습니다. 대시보드 빌드 및 열람은 실험 실행, 학습, 평가, 외부 게시를 하지 않습니다.

예제와 반복을 선택한 뒤 그래프의 개선점 또는 아래 목록을 누르면 후보 출처·
동치·깊이 판정을 볼 수 있다. 모델/ABC 비교가 아니며 실제 기기 확인과
Node 간이 DOM 확인은 다르다. 자세한 내용은 ../docs/ANYTIME_RESULTS.md.
